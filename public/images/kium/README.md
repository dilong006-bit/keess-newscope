# /kium 과정 카드 썸네일 — 샘플 자산 출처 기록

**⚠️ 이 디렉터리의 `*.sample.*` 파일은 디자인 참조용 샘플이며 실제 자산이 아닙니다.**

- 목적: `/kium#courses` 과정 카드의 **썸네일 듀얼 모드(이미지/텍스트)** 를 한 그리드 안에서 비교 검증하기 위한 임시 이미지.
  이미지 모드에서 과정명이 놓이는 자리(썸네일 영역 밖 · 카테고리 라벨 아래 · 설명글 바로 위)를 디자이너가 화면에서 확인하는 용도.
- 근거 문서: `ref/kium/spec/KEESS_인재키움프리미엄_썸네일듀얼모드_기술명세서_v1.0_260807.md` (§1~§5),
  `KEESS_G2-01-02_인재키움프리미엄_썸네일듀얼모드_빌드_기술명세서_및_프롬프트_v1.0_260810` (§5)
- 처리 방침: 실제 촬영·제작 자산이 입고되면 **파일 교체 + `lib/kium/data.ts`의 `thumbSrc` 경로 수정**.
  끝내 입고되지 않으면 **오픈(8/19) 전 `data.ts`의 `thumbSrc` 3줄과 본 파일들을 삭제**하여 전건 텍스트 모드로 되돌린다.
  추적 장치: 파일명의 `.sample.` · `data.ts`의 `// [샘플]` 주석 · 본 README.
