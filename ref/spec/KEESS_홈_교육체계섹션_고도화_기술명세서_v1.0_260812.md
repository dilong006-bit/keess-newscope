## 2. 반영 원칙

1. **레이아웃·슬라이드 로직 불변** — 슬라이드 구성·이미지 카드·도트 인디케이터·전환 애니메이션을 변경하지 않는다. 오픈 D-1 회귀 위험 최소화가 최우선이다.
2. **데이터/프레젠테이션 분리 준수** — 카피·경로는 데이터 소스에서, 마크업·스타일은 컴포넌트에서 수정한다. 저장소가 이미 이 구조(`data/home.ts` ↔ `components/sections/home/*.tsx`)를 따르고 있으므로 그대로 승계한다.
3. **디자인 토큰 우선** — 신규 hex·폰트·토큰 정의 금지. 이미 정의된 중립 텍스트 토큰을 찾아 적용한다.
4. **원인 제거** — 미노출 결함은 색을 덮지 않고 하드코딩 자체를 제거한다. 동일 패턴은 홈 전체에서 스윕한다.
5. **근거 없는 카피 생성 금지** — 본 명세서 5장 표에 없는 문구를 임의로 만들거나 다듬지 않는다.
6. **범위 한정** — 홈 교육체계 섹션. 타 페이지에서 동일 결함 발견 시 **수정하지 말고 목록만 보고**한다.

## 4. 구현 명세 — F1 Pillar 진입 동선

### 4-1. 데이터 — `href` 필드 추가

슬라이드 데이터 배열의 각 요소에 `href`를 추가한다. **인덱스 기반 하드코딩(`i===0 ? '/ax-ai' : …`) 금지.**

```ts
// 논리 모델 — 실제 필드명은 저장소 스키마에 맞춘다
{
  num: '01',
  eyebrow: 'AX·AI 전환',
  title: '...',
  badge: 'AI Transformation',
  items: [...],
  href: '/ax-ai',        // ← 신규
}
```

| 슬라이드 | `eyebrow` | `href` |
|:--:|---|---|
| 01 | AX·AI 전환 | `/ax-ai` |
| 02 | 리더십·조직 | `/leadership` |
| 03 | HRD 통합 솔루션 | `/hrd` |
| 04 | 콘텐츠 솔루션 | `/content` |

### 4-2. 마크업 — stretched-link 패턴

**중첩 앵커 금지.** 카드를 `<Link>`로 감싸고 내부에 CTA `<a>`를 두면 HTML 무효 + 접근성 오류다.

```
슬라이드 컨테이너  position: relative
├─ 이미지 카드
└─ 텍스트 블록
   ├─ 번호 / 아이브로우 / 헤드라인 / 구분선
   ├─ 서브아이템 3
   ├─ (03번만) 마무리 문구
   └─ CTA  <Link href={s.href}>          ← DOM상 유일한 앵커
           ::after { position:absolute; inset:0; }   ← 컨테이너 전체로 클릭 영역 확장
```

| # | 요구 |
|:--:|---|
| 4-2-1 | 슬라이드 컨테이너에 `position: relative` 부여 |
| 4-2-2 | CTA만 실제 `<Link>` (Next.js면 `next/link`). `target="_blank"` 금지 |
| 4-2-3 | CTA `::after`로 컨테이너 전체를 덮어 카드·텍스트 어디를 클릭해도 라우팅 |
| 4-2-4 | 도트 인디케이터는 링크 오버레이보다 **위 z-index**에 두어 클릭 가로채지 않게 한다 |
| 4-2-5 | CTA 시각 라벨 `자세히 보기` + 우향 화살표 |
| 4-2-6 | `aria-label`은 아이브로우 포함 — `AX·AI 전환 자세히 보기` 형태 4종 |
| 4-2-7 | CTA에 `data-cta="home-pillar-01"` ~ `home-pillar-04` 부여 |
| 4-2-8 | **03번은 마무리 문구 아래**에 CTA 배치 (4개 슬라이드 CTA 위치 논리 통일) |

### 4-3. 제스처 충돌 방지

슬라이드가 드래그·스와이프로 전환되므로, 드래그 후 손을 뗄 때 라우팅이 발동하면 안 된다.

| # | 요구 |
|:--:|---|
| 4-3-1 | `pointerdown` 좌표 저장 → `pointerup` 좌표와의 이동 거리 계산 |
| 4-3-2 | 이동 거리 **10px 초과** 시 클릭 이벤트를 `preventDefault()` 처리 |
| 4-3-3 | 키보드(Enter) 진입은 이 판별의 영향을 받지 않는다 |

### 4-4. 접근성·반응형

| # | 요구 |
|:--:|---|
| 4-4-1 | Tab 포커스 이동 가능 · 포커스 링 가시 · Enter로 이동 |
| 4-4-2 | 모바일 CTA 터치 타깃 **44×44px 이상** |
| 4-4-3 | 호버 상태 변화는 **기존 디자인 토큰 범위 내** 최소한으로 |
| 4-4-4 | PC(≥1024) / TB(768~1023) / MO(<768) 전 구간에서 클릭 정상 |
