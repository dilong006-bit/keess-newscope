## I. 요구사항 분석 및 전략

### 1-1. 문제 정의

「KG에듀원 교육체계」 섹션은 홈에서 **4개 Pillar를 처음 소개하는 관문**이다. 방문자가 자사에 맞는 교육 영역을 판별하고 해당 페이지로 넘어가는 첫 분기점이지만, 현재 세 가지 문제로 그 역할을 못 하고 있다.

| # | 문제 | 성격 | 영향 |
|:--:|---|---|---|
| P1 | 01~04 슬라이드에 **P1~P4 진입 동선이 없다** | 기능 누락 | 관심 Pillar를 확인해도 다음 행동으로 이어지지 못함. GNB로 되돌아가야 함 |
| P2 | 서브아이템 라벨 12개 + 마무리 문구 1개가 **흰색으로 렌더링되어 미노출** | 치명적 결함 | 각 Pillar의 핵심 3요소 위계가 사라짐. 03번 신뢰 문구(공공기관 레퍼런스) 완전 소실 |
| P3 | 카피에 **대상 페이지에 없는 용어·수치**가 포함됨 | 콘텐츠 정합 | `텐트진단`·`알림톡`·`AI 성숙도 4단계` 등. 홈에서 본 내용을 상세 페이지에서 찾을 수 없음 |

> **방향성**: "보여주기만 하는 소개 섹션에서 → 판별하고 진입시키는 관문으로"

### 1-2. 솔루션 강점

- **기존 레이아웃·슬라이드 로직을 유지**한 채 진입 동선만 얹는다. 오픈 D-1 시점의 회귀 위험을 최소화한다.
- 카피를 **각 Pillar 페이지의 실제 문구로 승계**해, 홈↔상세 간 메시지가 1:1로 이어지게 한다.
- 미노출 결함은 색을 덮지 않고 **원인(하드코딩)을 제거**해 재발을 차단한다.

### 1-3. 하드 제약

| 제약 | 내용 |
|---|---|
| C1 | **오픈 D-1** — 2026-08-13(목) 1차 오픈 대상. 구조 변경·리팩토링 금지 |
| C2 | **레이아웃·슬라이드 전환 로직 불변** — 도트 인디케이터 4개, 슬라이드 순회 동작 유지 |
| C3 | **디자인 시스템 내 처리** — 신규 색상값·폰트·토큰 정의 금지 |
| C4 | **근거 없는 카피 생성 금지** — 대상 페이지에 존재하지 않는 용어·수치·실적은 쓰지 않는다 |
| C5 | **범위 한정** — 홈 교육체계 섹션. 타 페이지는 발견 시 보고만 |

## II. 요구사항 해석 (Interpretation)

### R1 — Pillar 진입 동선

- **표면 요청**: "01, 02, 03, 04 클릭 시 P1, P2, P3, P4로 이동할 수 있어야 합니다."
- **진짜 의도**: 홈에서 교육 영역을 판별한 방문자를 **이탈 없이 해당 Pillar 페이지로 넘긴다.**
- **해결 문제**: 관심 영역을 확인하고도 GNB로 되돌아가야 하는 단절. 4개 Pillar 페이지의 유입 손실.
- **성공한 모습**: 4개 슬라이드 어디를 클릭해도 해당 Pillar 페이지로 이동하고, 클릭 가능하다는 사실이 시각적으로 드러난다.

### R2 — 미노출 텍스트 결함

- **표면 요청**: "폰트 색이 왜 화이트로 되어서 잘 안 보이는 문구들이 있는지요? 해당 결함도 같이 수정."
- **진짜 의도**: 기획 산출물이 **의도한 정보 위계대로 읽히게** 한다.
- **해결 문제**: 라벨이 안 보여 3요소 구조가 무너지고, 03번 공공기관 레퍼런스 문구가 통째로 사라진 상태.
- **성공한 모습**: 13개 텍스트가 드래그 없이 보이고, 라벨이 보조 설명글보다 위계가 높으며, 명도대비 4.5:1 이상.

### R3 — 마침표 규칙

- **표면 요청**: "'동시접속 2만·ISMS 전용 시스템.'와 같은 명사형 문장에 '.' 마침표는 불필요. 보조 설명글로 밝은 회색으로 노출되고 있는 문구에서만 마침표를 제외."
- **진짜 의도**: **UI 역할별로 문장 규칙을 고정**해 카피 품질 편차를 없앤다.
- **해결 문제**: 같은 리스트 안에 서술형·명사형이 섞이고 마침표 유무가 제각각인 상태.
- **성공한 모습**: 헤드라인=서술형+마침표, 보조 설명글=명사형+마침표 없음. 예외 0건.

### R4 — 근거 없는 표현

- **표면 요청**: "텐트 진단이라는 표현이 없다면 사용하지 않겠습니다. 현재 '리더십·조직' 화면 구성 기준으로 적합한 문구로 대체."
- **진짜 의도**: 홈 요약 카피가 **상세 페이지에서 검증 가능**해야 한다.
- **해결 문제**: 홈에서 본 용어를 상세 페이지에서 찾을 수 없어 기획 신뢰도가 훼손되는 상태.
- **성공한 모습**: 홈 교육체계 12개 보조 설명글의 모든 용어·수치가 대상 Pillar 페이지에 근거를 갖는다.

### R5 — 품질 기준

- **표면 요청**: "① 어색한 문구가 없어야 함 ② 어색한 표현이 없어야 함 ③ 문구가 보이지 않는 등의 치명적 결함이 없어야 함"
- **진짜 의도**: 개별 수정의 합이 아니라 **섹션 전체의 완성도**를 판정 기준으로 삼는다.
- **해결 문제**: 부분 수정 후 남는 불일치(예: 마침표만 떼어 서술형이 어색해지는 것).
- **성공한 모습**: 4개 슬라이드를 순회했을 때 걸리는 문장·안 보이는 문구가 0건.

**요구사항**

| # | 내용 |
|:--:|---|

| F2-2 | 라벨은 보조 설명글보다 **위계가 높다** (더 진한 색 + 굵은 굵기) |

**성공한 모습**
4개 슬라이드를 순회했을 때 안 보이는 텍스트가 0건이고, 홈 전체에 흰색 하드코딩이 남아 있지 않다.

### 5-4. F3 — 카피 문장 규칙 정립 (Must)

**규칙**

| 역할 | 어투 | 마침표 |
|---|---|:--:|
| 헤드라인 | 서술형(`~습니다`) | **유지** |
| 보조 설명글 | **명사형** | **제거** |
| 라벨 · 마무리 문구 | 명사형·구절형 | 없음 |

> **설계 판단**: 보조 설명글에서 마침표만 떼면 `현 위치를 봅니다` 처럼 **서술형인데 마침표가 없는 문장**이 남아 더 어색해진다(R5 ① 위반). 따라서 마침표 제거와 명사형 전환을 **한 세트**로 정의한다.

**성공한 모습**
보조 설명글 12건이 전부 명사형·마침표 없음이고, 헤드라인 4건이 전부 서술형·마침표 있음이다. 예외 0건.

### 5-5. F4 — 콘텐츠 정합성 확보 (Must)

**원칙**: 홈 교육체계의 보조 설명글은 각 Pillar 페이지 콘텐츠의 요약이다. **대상 페이지에 존재하지 않는 용어·수치는 쓰지 않는다.**
