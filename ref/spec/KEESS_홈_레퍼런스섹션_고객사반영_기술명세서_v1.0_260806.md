## 2. 반영 원칙

1. **전달본이 정본** — 사명 표기(국문/영문, 그룹·지주 표기, 괄호 병기)를 임의 교정·통일하지 않는다. 현행과 표기가 다른 경우에도 전달본을 따른다. 예: `POSCO→포스코`, `KGM→KG모빌리티`, `동원→동원그룹`, `롯데→롯데지주`, `아주→아주그룹`, `LS→LS그룹`, `KG→KG그룹`, `한국교육방송공사(EBS)` 괄호 포함 그대로.
2. **전면 교체 (diff 병합 금지)** — 현행 목록과 합치지 않는다. 전달본에 없는 기존 16개사(삼성화재·신한라이프·동양생명·하나손해보험·메리츠화재·KB생명보험·신한투자증권·신한카드·동국제강·KYOCERA·NH농협은행·KDB산업은행·BNK부산은행·DGB대구은행·새대한공인중개사협회·대한치과의사협회)는 **노출 목록에서 제외**된다(사업팀 협의 결과로 간주).
3. **데이터만 변경** — `data/home.ts` 1개 파일 2곳 수정. `HomeReferences.tsx`(홀짝 2행 자동 분배·마퀴·reduced-motion 폴백)와 스타일은 무변경가 원칙.
4. 캡션 `cap: '레퍼런스·사례 (노출 협의 기준)'`은 유지 (전달본에 별도 지시 없음 — 협의 기준 노출이라는 사실관계 지속).
