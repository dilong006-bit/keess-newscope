## 게이트

**0단계(소스 실사)를 마치면 기술명세서 §3-2의 6개 항목을 먼저 보고하고 멈춘다.** 내가 확인한 뒤 1단계부터 진행한다.

- 추측으로 코드를 쓰지 말 것. 반드시 실제 코드를 읽고 구조를 파악한 뒤 수정한다.
- 파일 경로·상수명·필드명은 실사 결과에 맞춘다. 기술명세서의 스키마 예시는 **논리 모델**이다.
