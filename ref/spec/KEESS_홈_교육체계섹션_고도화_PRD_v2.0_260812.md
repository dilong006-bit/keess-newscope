## I. 요구사항 분석 및 전략

### 1-1. 문제 정의

「KG에듀원 교육체계」 섹션은 홈에서 **4개 Pillar를 처음 소개하는 관문**이다. 방문자가 자사에 맞는 교육 영역을 판별하고 해당 페이지로 넘어가는 첫 분기점이지만, 네 가지 문제로 그 역할을 못 하고 있다.

| # | 문제 | 성격 | 영향 |
|:--:|---|---|---|
| P1 | 01~04 슬라이드에 **Pillar 진입 동선이 없다** | 기능 누락 | 관심 Pillar를 확인해도 다음 행동으로 이어지지 못함 |
| P2 | 서브 타이틀 12개 + 마무리 문구 1개가 **흰색으로 렌더링되어 미노출** | 치명적 결함 | 3요소 위계 소실. 03번 공공기관 레퍼런스 완전 소실 |
| P3 | 카피가 **상세 페이지의 핵심 축과 어긋난다** | 콘텐츠 정합 | 홈에서 본 내용이 상세에서 구체화되지 않음. 정보 연속성 단절 |
| P4 | 카피에 **상세 페이지에 없는 용어·수치**가 포함됨 | 신뢰도 | `텐트진단`·`알림톡`·`AI 성숙도 4단계` |

**P3의 구체적 양상 — 상세 페이지 대비 카피 미스매치**

| Pillar | 상세 페이지 중심축 | 기존 홈 카피 | 진단 |
|---|---|---|---|
| P1 | 진단 → 맞춤 설계 → 학습·실행 → 성과 측정·확산 | 진단으로 시작 / 직무로 좁히고 / 성과로 확인 | 흐름은 맞으나 내용이 얕음 |
| P2 | 진단 → 성장단계별 역량개발 → 현업적용·조직확산·문화정착 | 격차를 보고 / 역량을 좁히고 / 단계로 키우고 | **다면진단 개념이 상세에 없음.** 6대 역량·5단계 체계 미반영 |
| P3 | **시스템 / 운영 / 제작 3축 풀스택** + KGESA + AI 학습지원 | 시스템 안정 / 운영 밀착 / 성과 보고 | **판매 솔루션 구조가 아니라 운영 품질 서술.** 가장 큰 미스매치 |
| P4 | 8,000여 과정 · 6개 체계 · 매월 100+ 신규 + 자체 제작·파트너 | 직무·비즈니스 / 외국어·자격 / 조직·교양·법정 | **콘텐츠 분류표에 그침.** 규모·확장성 미노출 |

> **방향성**: "보여주기만 하는 소개 섹션에서 → 상세 페이지의 핵심을 정확히 예고하는 관문으로"

### 1-2. 솔루션 강점

- **홈 3개 메시지 = 상세 페이지 핵심 축**으로 정렬해, 진입 후 "홈에서 본 내용이 여기서 구체화된다"는 정보 연속성을 만든다.
- 4개 Pillar의 역할이 **서로 겹치지 않게** 분리된다 — P1 전환 프로세스 / P2 리더십 성장체계 / P3 HRD 풀스택 / P4 콘텐츠 공급 역량.
- 기존 레이아웃·슬라이드 로직을 유지한 채 카피·색·링크만 교체해 오픈 D-1 회귀 위험을 최소화한다.

### 1-3. 하드 제약

| 제약 | 내용 |
|---|---|
| C1 | **오픈 D-1** — 2026-08-13(목) 1차 오픈 대상. 구조 변경·리팩토링 금지 |
| C2 | **레이아웃·슬라이드 전환 로직 불변** — 도트 인디케이터 4개, 슬라이드 순회 동작 유지 |
| C3 | **디자인 시스템 내 처리** — 신규 색상값·폰트·토큰 정의 금지 |
| C4 | **카피 정본 준수** — §5-7 표 외의 문구를 임의로 만들거나 다듬지 않는다 |
| C5 | **범위 한정** — 홈 교육체계 섹션. 타 페이지는 발견 시 보고만 |

## II. 요구사항 해석 (Interpretation)

### R1 — Pillar 진입 동선

- **표면 요청**: "01, 02, 03, 04 클릭 시 P1, P2, P3, P4로 이동할 수 있어야 합니다."
- **진짜 의도**: 홈에서 교육 영역을 판별한 방문자를 **이탈 없이 해당 Pillar 페이지로 넘긴다.**
- **해결 문제**: 관심 영역을 확인하고도 GNB로 되돌아가야 하는 단절.
- **성공한 모습**: 4개 슬라이드 어디를 클릭해도 해당 Pillar 페이지로 이동하고, 클릭 가능하다는 사실이 시각적으로 드러난다.

### R2 — 미노출 텍스트 결함

- **표면 요청**: "폰트 색이 왜 화이트로 되어서 잘 안 보이는 문구들이 있는지요? 해당 결함도 같이 수정."
- **진짜 의도**: 기획 산출물이 **의도한 정보 위계대로 읽히게** 한다.
- **해결 문제**: 서브 타이틀이 안 보여 3요소 구조가 무너지고, 03번 공공기관 레퍼런스가 사라진 상태.
- **성공한 모습**: 13개 텍스트가 드래그 없이 보이고, 서브 타이틀이 보조 설명보다 위계가 높으며, 명도대비 4.5:1 이상.

### R3 — 문장 규칙

- **표면 요청**: "메인 헤드라인은 서술형+마침표, 1~3 서브 타이틀과 보조 설명은 명사형+마침표 없음으로 통일."
- **진짜 의도**: **UI 역할별로 규칙을 고정**해 카피 품질 편차를 없앤다.
- **해결 문제**: 같은 리스트 안에 서술형·명사형이 섞이고 마침표 유무가 제각각인 상태.
- **성공한 모습**: 3단 규칙(헤드라인 / 서브 타이틀 / 보조 설명)에 예외 0건.

### R4 — 상세 페이지 정합

- **표면 요청**: "실제 P1~P4 상세 기획안을 기준으로 홈의 교육체계 섹션이 상세 페이지의 핵심을 정확히 예고하도록."
- **진짜 의도**: 홈 3개 메시지를 **상세 페이지의 핵심 서비스 구조 또는 가치 흐름**과 일치시킨다. 단순 특징 나열에서 벗어난다.
- **해결 문제**: P3가 판매 솔루션이 아니라 운영 품질을 말하고, P4가 분류표에 그치는 구조적 미스매치.
- **성공한 모습**: 4개 Pillar 역할이 겹치지 않고, 각 상세 페이지 진입 시 홈 메시지가 그대로 구체화된다.

### R5 — 품질 기준

- **표면 요청**: "① 어색한 문구 0 ② 어색한 표현 0 ③ 문구 미노출 등 치명적 결함 0"
- **진짜 의도**: 개별 수정의 합이 아니라 **섹션 전체의 완성도**를 판정 기준으로 삼는다.
- **성공한 모습**: 4개 슬라이드를 순회했을 때 걸리는 문장·안 보이는 문구가 0건.

### R6 — 배포

- **표면 요청**: "해당 파일을 기준으로 클로드 코드에게 전달하여 빌드, 푸시 진행하겠습니다."
- **진짜 의도**: 로컬 수정에 그치지 않고 **기획 프로토타입 배포본에 반영**해 개발팀·유관부서가 확정안을 볼 수 있게 한다.
- **성공한 모습**: 검증 통과 → 커밋 → 푸시 → 배포본에서 재확인.

### 5-5. F4 — 콘텐츠 정합성 확보 (Must)

**설계 원칙 2가지**

1. **홈은 상세를 설명하지 않는다.** "이 영역에 들어가면 무엇을 해결할 수 있는가"를 3개 메시지로 압축한다.
2. **서브 타이틀 1~3은 특징 나열이 아니라 상세 페이지의 핵심 서비스 구조 또는 가치 흐름**으로 구성한다.

**Pillar별 재설계 근거**

| Pillar | 상세 페이지 중심축 | 홈 3개 메시지 |
|---|---|---|
| **P1** | 진단 → 맞춤 설계 → 학습·실행 → 성과 측정·확산 | 현 수준 진단 → 직무별 맞춤 설계 → 성과 측정·확산 |
| **P2** | 진단 → 성장단계별 역량개발 → 현업적용·조직확산·문화정착 | 현 수준 진단 → 단계별 역량 개발 → 조직문화 정착 |
| **P3** | **시스템 / 운영 / 제작 3축 풀스택** + KGESA + AI 학습지원 | 맞춤형 학습 플랫폼 → 통합 교육 운영 → 콘텐츠 자체 제작 |
| **P4** | 8,000여 과정 · 6개 체계 · 매월 100+ 신규 + 자체 제작·파트너 | 8,000여 개 과정 → 6개 교육체계 → 제작·파트너 확장 |

**P3·P4가 가장 큰 변경인 이유**

- **P3** — 기존 `시스템 안정 / 운영 밀착 / 성과 보고`는 운영 **품질**을 서술한다. 상세 페이지는 처음부터 `시스템 / 운영 / 제작`을 아키텍처로 제시하고 각각을 판매 축으로 정의한다. **실제 판매하는 솔루션 자체를 설명하는 편이 강하다.**
- **P4** — 기존 `직무·비즈니스 / 외국어·자격 / 조직·교양·법정`은 "어떤 콘텐츠가 있는가"만 보여주는 **분류표**다. 최종안은 **규모 → 탐색 체계 → 공급·확장 능력**까지 보여줘 사업 경쟁력을 설명한다.

**제거되는 근거 없는 표현 (전역 검색 0건이어야 함)**

| 표현 | 확인 결과 |
|---|---|
| `텐트진단` / 자가·타인 인식 격차 | `/leadership`에 용어·개념 모두 없음 |
| `알림톡` · `핫라인` · `강사 품질관리` | `/hrd`에 3요소 전부 없음 |
| `AI 성숙도 4단계` | `/ax-ai`에 `4단계` 없음. 같은 슬라이드 `5단계`와 수치 충돌 |
| `신임부터 임원까지` | `신임`은 오기, `임원`은 6단계 중 5번째 |

| **E10** | **서브 타이틀 `8,000여 개 과정` 등 숫자 포함** | 숫자·쉼표가 줄바꿈으로 끊기지 않게 확인 |

## IX. 성능 & 확장성

- 정적 데이터·CSS 변경 중심. 번들 영향 무시 가능
- `href`를 데이터 필드로 두어 **Pillar 추가·경로 변경 시 데이터만 수정**
- 계측 속성(`data-cta`)을 미리 부여해 `[G2-10] GTM·GA4` 단계에서 코드 수정 없이 이벤트 바인딩 가능
