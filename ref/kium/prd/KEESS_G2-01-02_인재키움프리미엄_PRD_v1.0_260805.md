## I. 요구사항 분석 (4단계 해석)

**[R1] 탭 구성 상세(수정안) 구현**
- 표면 요청: 히어로+탭1(사업소개 4섹션)+탭2(과정안내 카드+CTA) 1페이지
- 진짜 의도: 8/19 오픈 일정 내에 인재키움 사업의 마케팅 대표 페이지를 확보 — 영업이 링크 하나로 안내 가능한 상태
- 해결 문제: 현재 인재키움 안내 자산이 PDF·엑셀 산재 → 고객 전달 불가
- 성공한 모습: /kium URL 하나로 제도 설명·자격 확인·과정 카탈로그·문의 접수가 완결

**[R2] 썸네일 = 색상 구분 + 과정명 기입**
- 표면 요청: 과정 분류에 맞춰 색상으로 썸네일 구분
- 진짜 의도: 과정별 이미지 자산이 없는 제약 하에서 카탈로그가 빈약해 보이지 않게
- 해결 문제: 실사·제작 썸네일 부재, 19개 과정의 시각 구분 수단 없음
- 성공한 모습: 이미지 0장으로도 카테고리가 한눈에 구분되는 일관된 카드 그리드

**[R3] 진입 경로 2종 동시(홈 히어로 + GNB 이벤트 칩)**
- 표면 요청: 홈 히어로 슬라이드 + GNB 우측 칩
- 진짜 의도: 캠페인 집중 노출과 전 페이지 상시 인지의 병행
- 성공한 모습: 어느 페이지에서든 1클릭으로 /kium 도달

**[R4] 공통 원칙 — 임의 생성 금지 / 정의 정보 최대 활용** (사용자 확정)
- 성공한 모습: 화면의 모든 수치·문안이 소스 문서로 역추적 가능, 미확정 항목은 문안 교체만으로 반영되는 구조

**[R5] 최고급 프로토타입 — 가용 기술 총동원** (사용자 확정)
- 성공한 모습: 스킬(QA·스크린샷)·MCP(Figma)·코드형 리소스(lucide, 메시 토큰)를 활용한 프로덕션급 프로토타입

## II. 성공 메트릭
- 1차(정성): 사업팀·팀장 검수 통과, 8/19 오픈 포함
- 2차(정량, GA4 연계 후): /kium 유입 → 도입문의 제출(generate_lead, lead_type=kium) 전환. GA4/GTM 코드는 본 빌드에 직접 삽입하지 않음(기존 G2-10 원칙)

## III. 페르소나 (요약)
- **P1 중소기업 교육담당자**: "우리 회사가 대상인지, 얼마나 환급되는지"가 첫 질문 → 자격확인·지원율이 최상단 정보
- **P2 경영진/결재권자**: 비용 대비 효과 → "실부담 5% 내외" 체감과 과정 신뢰도
- 여정: 유입(히어로) → 제도 이해(탭1) → 자격 확인 → 과정 탐색(탭2) → 상세 확인 → 도입문의

## IV. 정보 아키텍처

```
/kium              1페이지 (해시 탭: #intro 기본, #courses)
 ├─ 히어로(공통) → 탭바 → 탭1[개요표→자격확인→신청절차→FAQ] | 탭2[필터→카드19→인라인패널]
 └─ CTA 밴드(도입문의, 양 탭 공통)
홈(/)              히어로 캠페인 슬라이드 1장 추가
공통 레이아웃       GNB 우측 이벤트 칩 → /kium
```
- GNB 정식 메뉴 편입 없음. 신규 라우트는 /kium 단일(상세 개별 라우트 없음 — 인라인 패널)

## VI. UI/UX 설계 원칙
UIUX 고도화전략 260805를 단일 기준으로 참조(중복 기술 생략). 핵심: 페이지 강조색 KG 퍼플 단일, 썸네일=콘텐츠 표면(1휴 6변주), 기존 토큰 100% 상속·신규 토큰 금지, 전 모션 morph·reduced-motion 강등, 필러 컬러(P1~P4) 사용 금지.

## VII. 기술 아키텍처 개요 (상세는 기술명세서)
- keess-newscope 저장소(Next.js App Router SSG) — 사회공헌 /csr 구현 관례(lib/·components/·app/·styles/ 구조, 기존 토큰) 승계
- 데이터: `lib/kium/data.ts` 정적 상수(사전 제작·검증 후 전달 — 사회공헌 data.ts 패턴). 서버·DB·ADMIN 없음
- 아이콘: lucide-react(npm, MIT). 실사·외부 이미지 0

## VIII. 엣지 케이스
- FAQ·CTA 항목 미확정 → 콘텐츠 상수 분리로 교체 대응 / 필터 0건 없음(카테고리당 ≥1) + 방어 문구 1종 / 해시 잘못된 값 → #intro 폴백 / JS 미동작 시 탭1 콘텐츠 기본 노출(SSG 마크업 순서)

## IX. 성능
- 썸네일 CSS 렌더(이미지 요청 0) → LCP는 히어로 텍스트. WebGL 카드 사용 금지(컨텍스트 상한). 패널 콘텐츠는 초기 HTML 포함(SEO·즉시 확장)
