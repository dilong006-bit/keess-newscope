## 0. 문서 규칙

## 1. 고도화 배경 — v1.0의 구조적 한계 4가지
1. **FAQ·CTA가 "미확정 슬롯"으로만 존재** — 이후 문안 초안·구성안이 확정되어 계약 수준으로 승격 필요
2. **환급 실무 정보 부재** — 신청절차가 추상 4스텝이었으나, 고용24 매뉴얼·KPC 게시글로 실무 조건(교육시작일 전 등록·출석 80%·서류 2종·환수 리스크)이 확보됨. 미반영 시 "행정 동행" 소구가 공허해짐
3. **외부 참고 링크가 경쟁 훈련기관(KPC)** — 탭구성상세의 [참고] URL을 그대로 게재하면 경쟁사로 트래픽 유출 + 원천 아닌 2차 가공 정보 안내
4. **수치 검증 게이트 부재** — 타사 게재 수치(한도 240%·지역별 환급율 세분)가 소스 간 상이함이 확인됨. 검증 없는 수치가 화면에 실리는 것을 막는 장치 필요

## 2. 요구사항 해석 (사용자 확정 4원칙)

**[R6] 정확한 정보 안내 (오제공 0)**
- 표면 요청: 잘못된 정보 없이 페이지 제작
- 진짜 의도: 정부사업 안내는 오류 시 기업의 실손실(환급 무산)로 직결 — 신뢰가 곧 상품
- 해결 문제: 소스 간 수치 상이(KPC vs RAPA vs 휴넷), 미확정 문안의 혼입 위험
- 성공한 모습: 화면의 전 수치·문안이 소스 대조표로 역추적되고, 미검증 수치는 구조적으로 렌더 불가

**[R7] 정보 구조·특성 최적 UI/UX** → baseline F2~F9 + UIUX 고도화전략 유지, 신규 정보(유의사항·실무 절차)의 자리 신설
**[R8] 심미 퀄리티** → UIUX 고도화전략(1휴 6변주 썸네일·모션 체계) 유지, 변경 없음

## 3. 변경·신설 기능 명세

### F5′ 신청절차 스텝퍼 — 콘텐츠 확정 (변경, Must)
- 4스텝 유지, 각 스텝의 '기업/KG에듀원' 2행을 확정 소스 기반 실무 문안으로 채움:
  1. 상담 신청 — 기업: 문의 접수 / KG: 지원대상·예상 규모 확인 지원
  2. 과정 설계 — 기업: 니즈 협의 / KG: 사전진단·모듈 맞춤 구성
  3. 정부 신청·선납 — 기업: 고용24 기업회원 가입 → **교육시작일 전 훈련생 등록(소급 불가)** → 교육비 선납 / KG: 등록 절차·필요 정보 안내
  4. 교육·환급 — 기업: 수료(출석 80%) 후 고용24 비용신청(납입 영수증+수료증 2종) / KG: 수료증·영수증 발급, 신청 방법 안내
- Done when: 스텝 문안 전건이 근거 소스(매뉴얼·KPC 게시글) 표기와 일치, "대행" 표현 미사용(사업 확정 전 "안내·동행" 유지)

### F6′ FAQ 확정 7문항 (변경, Must)
- 초안 v1.0의 7문항을 content.ts에 탑재(status: draft), 사업 검수 시 confirmed 전환
- 검수 대기 후보 +2(환급 절차 상세 / 기존 사업주훈련과의 차이)는 검수 회신과 함께 결정
- Done when: draft 상태 시각 표기, 문안 교체 시 코드 수정 0

### F10′ CTA — 확정안으로 개정 (변경, Must)
- v1.0의 "관심 과정 select 19종" 폐기. 확정안: 기존 도입문의 폼 재사용 + **관심 영역 칩 '정부 지원' 1개 추가** + /kium 경유 시 ⓐ칩 자동 선택(해제 가능) ⓑ`lead_source: 'kium'` 시스템 태깅(비노출) ⓒ상세 패널 경유 시 문의 내용 "[관심 과정: OO]" 프리필(편집 가능)
- 신규 수집 항목 0 — G2-11 정보보호팀 검토 전제("기존 폼 재사용, 신규 수집 없음") 유지가 계약
- Done when: 태깅이 제출 데이터에 포함되고 UI에 미노출, 칩 해제 가능

### F14 유의사항 캡션 (신설, Should)
- 신청절차 섹션 하단 caution 3종: ①교육시작일 전 훈련생 등록 필수(소급 불가) ②수료 기준 출석 80% 이상 ③지원한도 초과 지급분 환수 가능
- 근거: KPC 게시글 24183·고용24 매뉴얼. 리스크 정직 고지 = 정부사업 페이지의 신뢰 장치(R9)
- Done when: caution 3종 노출, 문안 소스 대조 일치

### F15 공식 원천 링크 체계 (신설, Must)
- 외부 링크 전건을 공식 원천으로 통일: 자격확인 → 고용24(work24.go.kr)·고용산재보험 토탈서비스 / 제도 근거 → HRDK 공고(2025-237호) 표기
- **경쟁 훈련기관(KPC 등) 링크 게재 금지** — 탭구성상세의 [참고] URL은 기획 참고용이었음을 사업팀에 고지(확인 항목)
- Done when: 외부 링크 전건이 정부·공단 도메인, 새창+rel+텍스트 고지

### F16 수치 검증 게이트 (신설, Must)
- content.ts의 제도 수치 항목에 `verified: boolean` + `source: string` 필수화. verified=false인 수치는 **렌더 자체가 차단**되고 대체 문구("기업별 상이 — 상담 시 확인") 출력
- 현재 검증 대기: 환급율 지역·방식 세분(수도권 90/비수도권 95 등), 신청 기한 세부, 환급 소요기간 — 공고 2025-237호 원문 확인 후 verified 전환
- (2026-08-05 갱신) 공단 홍보자료(별첨5)로 verified 전환 완료: 지원율 90%(실 납부액 기준, 비수도권 우대) / 지원한도 개산보험료의 240%(최소 500만원) / 사업주 명의 계좌 환급 / 고용24 한도 조회 경로
- Done when: 미검증 수치가 화면에 나타날 수 없음을 코드 레벨로 보장

### C3 고용24 비용신청 매뉴얼 다운로드 (신설, Could)
- HRDK 확인·배포 공식 매뉴얼 PDF를 신청절차 섹션에서 다운로드 제공(출처 표기). 게재 가능 여부 사업 확인 후
