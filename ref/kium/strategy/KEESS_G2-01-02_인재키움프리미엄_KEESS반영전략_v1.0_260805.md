## 1. 포지셔닝 — 물량이 아닌 설계

- KPC "국내 최다 730개" 물량 소구와 정면 경쟁 불가·불필요. KEESS 축: **"19개 검증 과정 + 사전진단 기반 맞춤 구성 + 환급 행정 동행"**
- "맞춤 설계"와 "행정 동행"은 히어로 하단 설명 확정 카피("맞춤형 교육 설계부터 복잡한 환급 절차까지")에 이미 내장 — 페이지 전체가 이 두 축을 시각적으로 증명하는 구조로 설계
- 전 과정 AI 모듈 내장(일반형 과정에도 생성형 AI 3H 공통 편성 — KG에듀원 자체 설계로 확인)은 카탈로그 관통 메시지로 활용 가능

## 2. IA·진입 경로

```
홈(/)
 ├─ 히어로 섹션: 인재키움 캠페인 슬라이드/배너 (확정 카피)
 └─ GNB 우측 이벤트 칩: 전 페이지 상시 노출 → /kium(가칭)

/kium (1페이지)
 ├─ 히어로 (공통)
 ├─ 탭1. 사업소개  : 지원개요표 → 자격확인가이드 → 신청절차 → FAQ
 ├─ 탭2. 과정안내  : 카테고리 필터 칩 + 카드 그리드(19) + 확장 상세 패널
 └─ CTA 밴드      : 도입문의 폼 (양 탭 하단 공통)
```

- 라우트명 개발 착수 전 확정 필요(/kium 가칭). 사회공헌 /csr 오타 사례 재발 방지
- 탭1 내부는 섹션 스크롤 + (분량에 따라) 미니 앵커 검토 — 에이블런의 스티키 앵커 칩 패턴은 원페이지가 매우 길 때 유효하며, KEESS는 2탭 구조라 탭이 그 역할을 대체. 앵커는 탭1이 길어질 경우에만 추가

## 3. 화면 설계 — 탭1 사업소개

### 3-1. 히어로
- 카피는 확정본 그대로. "90~95%" 숫자를 디스플레이 타이포(자간 -0.02~-0.03em, tabular-nums)로 최대 강조
- 신뢰 장치: 주관기관(고용노동부·한국산업인력공단) **텍스트 표기**를 히어로 또는 지원개요표 상단에 — 에이블런은 정부 로고 3개 병렬이나, 정부기관 로고 사용 규정 확인 전에는 텍스트 우선(원칙1의 연장: 확인 안 된 사용권 미전제)

### 3-2. 지원개요표
- 4항목 확정 데이터로 2열 정의표(라벨+값). "지원 한도는 기업별 상이" 단서 유지
- (옵션·사업 확인 후) KPC식 금액 환산 병기: "40만원 과정 기준 기업 실부담 2~4만원" — 단가표 기반 단순 산술이나, 환급율 변동 조건 단서 필수라 사업 확인 후 반영

### 3-3. 자격확인가이드 — KPC recipient 페이지 구조 차용
- 보유 정보 기준 **3경로 분기**: ①기업 공동인증서(고용24 3스텝) ②사업장 관리번호(고용·산재보험 토탈서비스 3스텝) ③사업자등록번호만(외부 확인 링크)
- 우선지원대상기업 기준표 자체 게재 금지(KPC도 미게재 — 법령 개정 유지보수 리스크). "대규모기업 환급 불가" 제외 문구 명시
- UI: 01/02/03 넘버링 미니 스텝 카드 3열(모바일 세로 스택)

### 3-4. 신청절차 — 에이블런 4스텝 + 주체 구분 강화
- 상담신청 → 과정 설계 → 정부 신청·선납 → 교육 진행·환급 (4스텝 기본, 사업 검수로 확정)
- 각 스텝에 **"기업이 할 일 / KG에듀원이 함께하는 일"** 2행 병기 — 행정 동행 소구의 시각화(에이블런 핵심 전략 차용)
- 디자인: 원형 스텝퍼 + 진행할수록 브랜드 퍼플 심도가 깊어지는 연출(에이블런 관찰 → 진행감 원칙). 모션은 진입 stagger 40~60ms, ease-out 240ms(기존 .rv 패턴)

### 3-5. FAQ
- 5문항 구성안(사업 검수 대기): ①결제 방식(B2B→환급 구조) ②개인 신청 가능 여부 ③제도 vs 훈련기관 구분 ④환급 소요 기간 ⑤지원대상 확인 방법
- 기존 KEESS FAQ 아코디언 컴포넌트 재사용. 문안 확정 전 임의 답변 게재 금지(원칙1)

## 4. 화면 설계 — 탭2 과정안내

### 4-1. 카테고리 체계 (교육대상 기반 6그룹)

| # | 카테고리 | 과정 수 | 소속 과정 |
|---|---|---|---|
| 1 | 신입·온보딩 | 3 | On-Syncing / On-Performing / On-Powering |
| 2 | 승진자 | 3 | Role Up 사원~대리 / 과장~차장 / 부장 |
| 3 | 리더십 | 2 | 팀장 Re-Lead / 현장 플레잉 코치 |
| 4 | 임원 | 1 | 임원 역량개발 |
| 5 | AI 실무역량 | 3 | Agent / Data / AI 직무 특화 |
| 6 | 공통 직무역량 | 7 | 협상 / 스피치 / 구두보고 / 감성소통 / 공감대화 / 세대소통 / CS |

- 그리드 정렬 순서 = 성장단계 내러티브(신입→승진→리더→임원→AI→공통)
- 개요서 10종 소분류는 폐기하지 않고 카드 내 텍스트 라벨로 보존
- xlsx "일반형/AI융합형" 유형은 색이 아닌 **배지**로 처리(AI융합형 3종만 배지, 단가·성격 차별성 근거)
- 필터: 6칩 + 전체. 19개 소량이라 필터는 단일 축만(과잉 탐색 UI 금지 — 사회공헌 전략과 동일 원칙)

### 4-2. 썸네일 시스템 — 단일 휴 6변주 메시 그라디언트
- 전 썸네일 베이스 = KG 브랜드 퍼플 계열(#2E1A6B 앵커). 카테고리별로 메시 그라디언트 보조 정지점 색만 인접 휴 변주(신입=블루, 승진자=바이올렛, 리더십=딥인디고, 임원=네이비+골드 미량, AI=시안, 공통=뉴트럴 그레이 방향)
- 근거: KEESS "강조색 난립 금지·통일 베이스" 원칙과 "색상으로 구분" 요구의 양립 — 썸네일은 UI chrome이 아닌 콘텐츠 표면으로 정의하되, 1휴 6변주로 규율. 사회공헌 그라디언트 플레이스홀더와 시스템 연속
- 텍스트 규칙: 메시의 최암부를 텍스트 앵커 코너(좌하단)에 고정, 과정명 흰색 + 필요 시 미세 스크림, WCAG AA 필수 (썸네일에 과정명 기입은 원안 확정 요구)
- 구현: CSS radial-gradient 3~4겹 중첩, 카테고리당 정지점 좌표·색 토큰만 교체. 밴딩 방지 계단식 보간. 그레인 텍스처는 절제(기각 우선). 카드 호버 시 그라디언트 정지점 애니메이션 금지(가독성), 기존 카드 문법(sh1→sh2, -3px, 240ms)만
- 캐치: 카테고리 결정형(같은 분류=같은 표면) — Moodle식 랜덤 생성이 아닌 시스템 팔레트

### 4-3. 카드 anatomy (위→아래)
1. 썸네일(카테고리 메시 + 과정명) — 비율 고정(4:3 또는 1:1, 목업에서 확정)
2. 카테고리 라벨(6그룹) + AI융합형 배지(해당 시)
3. 과정명 텍스트(마케팅명, 2줄 말줄임) — 썸네일 내 기입과 별개로 본문 반복(접근성·검색성)
4. 서브카피 1줄(시트3 "과정 소개 요약" 압축 — 신규 작문 아님, 원문 압축만)
5. 메타 행: 대상 · 시간/일수(tabular-nums) · "정부지원 환급 대상" 인라인 배지
- 단가 비노출 유지(B2B 환급 구조상 원단가 노출 부적절 — 기존 판단), 정원·장소·연중상시는 상세 패널로

### 4-4. 상세 패널 (카드 클릭 시 확장)
- 19개 과정이 3개 시간 템플릿(14H=2H+3H×4 / 7H=1~2H+2~3H×3 / 6H=2H×3)으로 수렴 → **"도입 모듈 + 본 모듈 N개" 아코디언 단일 컴포넌트**로 전 과정 처리
- 구성: 훈련목표(시트3 리스트) → 교육구성 표(영역·주요 학습내용·시간 = 개요서 표 구조) → 과정 특장점 3단계(개요서 다이어그램의 웹 번안) → 공식 신청명 병기(과정명 기준 확정 시)
- 강사 정보 1차 미노출(익명 데이터뿐). 커리큘럼 세부내용은 시트3 원문 사용
- CTA: 패널 하단 "이 과정으로 도입문의" → 공통 폼으로 스크롤/이동(과정명 자동 선택)

## 5. CTA — 도입문의 폼 재구성(안)
- 기존 도입문의 폼 컴포넌트·동의 구조(G2-11 확정 흐름) 재사용
- 재구성 후보 항목(사업 회신 대기): 상시근로자 수(지원대상 판별 연관), 관심 과정(탭2 연동 프리셀렉트), 희망 교육 시기, 예상 인원
- 회신 무관 원칙: 필수 최소화, 동의 문구는 기존 확정 구조 그대로(신규 수집 항목 발생 시 G2-11 후속 재점검 트리거)
