## 2. 비주얼 아이덴티티

### 2-1. 색
- 페이지 강조색 = KG 브랜드 퍼플(#2E1A6B) 단일. 필러 컬러(P1~P4)는 이 페이지와 무관하므로 사용 금지(필러 소속 페이지가 아님)
- "정부지원 환급" 인라인 배지 = 기존 정부지원 옐로우 문법 그대로(의미 고정 유지)
- AI융합형 배지 = 신규 색 금지. surface 배경 + 퍼플 텍스트 + hairline 보더의 뉴트럴 배지로 처리, 색이 아닌 **라벨 텍스트**가 정보를 든다
- 썸네일 표면색은 UI 강조색이 아닌 콘텐츠 표면으로 정의(3장 시스템 참조) — 카드 본문·라벨·보더는 전부 무채색 유지

### 2-2. 타이포그래피
- 히어로 메인 카피: 기존 KEESS 헤드라인 체계(세리프 미사용 — Gowun Batang은 사회공헌 에디토리얼 전용 장치로 보존, 이 페이지는 비즈니스 캠페인 톤). "90~95%"만 디스플레이 스케일 상향 + 자간 -0.03em + `font-variant-numeric: tabular-nums`
- 카드 과정명: line-height 1.4, 2줄 말줄임. 썸네일 내 과정명: 15~17px 600, 흰색
- 메타 수치(14시간·2일·정원): tabular-nums 전역, 라벨 12px muted
- 위계는 크기보다 굵기 대비(600/400) 우선 — 카드 내부 폰트 크기 단계는 3단 이내

### 2-3. 형태·깊이·모션 (기존 토큰 상속)
- radius: 카드 20px, 썸네일 상단 concentric(카드 20 − 패딩 0 = 20, 하단 0), 칩 999px, 배지 12px
- shadow: sh1 기본 → sh2 호버 2단, 단일 드롭섀도 금지
- 모션: 진입 stagger 40~60ms + translateY 8px→0 + opacity(.rv 패턴), duration 240ms `cubic-bezier(.2,0,0,1)`, linear 금지. 상태 전환은 morph, pop 금지
- `prefers-reduced-motion` 시 전 애니메이션 opacity 전환만으로 강등

## 3. 썸네일 시스템 상세 스펙 (신규 발명 컴포넌트 ①)

### 3-1. 구조
- 비율 **4:3 고정**(3열 그리드에서 과정명 2줄+카테고리 여백 확보, 1:1은 7H·6H 과정의 짧은 제목에 과대, 16:9는 모바일 1열에서 텍스트 대비 면적 부족)
- 레이어: [베이스 그라디언트] → [메시 정지점 2~3개] → [텍스트 스크림(조건부)] → [과정명 + 카테고리 미니 라벨]

### 3-2. 카테고리 팔레트 (1휴 6변주 — 전 카테고리 베이스 #2E1A6B 계열 고정)

| 카테고리 | 보조 정지점 방향 | 의도 |
|---|---|---|
| 신입·온보딩 | 퍼플 → 블루 | 시작·신뢰 |
| 승진자 | 퍼플 → 바이올렛 | 전환·상승 |
| 리더십 | 퍼플 → 딥 인디고 | 무게·책임 |
| 임원 | 퍼플 → 네이비(+골드 미량 1정지점) | 격 |
| AI 실무역량 | 퍼플 → 시안 | 기술·미래 |
| 공통 직무역량 | 퍼플 → 뉴트럴 그레이 | 범용·안정 |

- 구현: `background: radial-gradient(A), radial-gradient(B), linear-gradient(base)` 3겹 중첩. 카테고리당 정지점 좌표·색만 CSS 변수 교체(`--mesh-a`, `--mesh-b`…). 정지점 간 명도·채도 계단식 보간으로 밴딩 방지
- 그레인 텍스처 기각(IR·미니멀 톤 유지, 사회공헌 판단과 동일)
- **결정성**: 같은 카테고리 = 같은 표면(랜덤 생성 금지). 시각적 그룹핑이 곧 정보 설계

### 3-3. 텍스트 규칙 (AA 필수)
- 최암부 정지점을 **좌하단 코너에 전 카테고리 공통 고정** → 과정명 앵커도 좌하단 통일(그리드 스캔 시 시선 정착점 일정 — 게슈탈트 정렬)
- 과정명 흰색 600. 대비 4.5:1 미달 지점 발생 시 하단 40% 높이에 `linear-gradient(transparent → rgba(20,10,50,.35))` 스크림 1겹
- 카테고리 미니 라벨: 좌상단 11px, 흰색 85% 불투명
- 호버: 그라디언트 정지점 이동 금지(가독성 원칙). 카드 공통 lift만

## 4. 화면별 상세 UI/UX

### 4-1. 진입 경로 2종
- **홈 히어로 슬라이드**: 기존 홈 히어로 문법에 캠페인 슬라이드 1장 추가. 카피는 확정 메인 카피 축약형, CTA "자세히 보기 → /kium". 자동 롤링은 기존 홈 정책 따름, reduced-motion 시 정지
- **GNB 이벤트 칩**: pill(radius 999px), 퍼플 배경 + 흰 텍스트 "인재키움 프리미엄" + 미세 dot 인디케이터. pulse·글로우 애니메이션 금지(전 페이지 상시 노출 요소의 모션은 공해). 호버 시 배경 명도만 1단 상승. 터치 타깃 44px 확보(칩 자체 높이 32px + 히트 영역 패딩)

### 4-2. 히어로(/kium 공통)
- 좌: 아이브로(확정 정보 기반 라벨) → 메인 카피(90~95% 디스플레이 강조) → 하단 설명 2문장(확정본) → 주관기관 텍스트 표기(고용노동부·한국산업인력공단) → CTA 2개(Primary "도입문의" / Ghost "지원대상 확인" → 탭1 자격확인 섹션 스크롤)
- 배경: 중립 베이스 유지. 풀블리드 다크(에이블런)는 기각 — KEESS 홈과의 조화(Harmony) 우선. 우측에 절제된 브랜드 그라디언트 오브젝트 1개 허용(그라데이션 허용 정책 범위 내)

### 4-3. 탭 바 (사업소개 | 과정안내)
- 시스템 표준 탭 문법: 텍스트 탭 + 언더라인 인디케이터. 인디케이터는 탭 전환 시 **슬라이드 morph 240ms**(즉시 교체 금지)
- 콘텐츠 전환: 나가는 패널 opacity 0 (120ms) → 들어오는 패널 opacity+translateY 8px (240ms). 좌우 슬라이드 캐러셀 전환은 기각(탭은 공간 은유가 아님 — HIG 일관성)
- URL 해시 동기화(`/kium#courses`): GNB 칩·홈 히어로에서 탭2 직행 딥링크 가능, 뒤로가기 자연 동작
- 키보드: role=tablist, 좌우 화살표 이동, aria-selected. 탭 전환 시 포커스는 패널 첫 헤딩으로
- 모바일: 탭 바 상단 sticky(스크롤 시 높이 축소 없음 — 2개뿐이라 축소 연출 불필요)

### 4-4. 탭1 — 지원개요표
- 2열 정의표(라벨 muted 13px / 값 600). "훈련비의 최대 90~95% 환급" 값만 퍼플 강조
- "지원 한도는 기업별 상이" → 값 옆 보조 문장 + "내 회사 한도 확인하기" 텍스트 링크 → 자격확인 섹션 앵커(불확실성을 행동으로 전환)
- 금액 환산 다이어그램은 사업 확인 후 삽입 슬롯만 예약(레이아웃 재편 없이 1행 추가 가능한 구조)

### 4-5. 탭1 — 자격확인가이드 (3경로 분기)
- 세그먼트 질문형 헤더: "무엇을 갖고 계신가요?" → 3카드(공동인증서 / 사업장 관리번호 / 사업자등록번호만)
- 각 카드 내부 01→02→03 미니 스텝(hairline 구분, 화살표 아이콘). 외부 이동 링크는 새창 + 새창 아이콘 + 스크린리더 "새 창에서 열림" 텍스트
- "대규모기업은 환급 대상이 아닙니다" 제외 고지를 섹션 하단 caption으로 명시(신뢰 = 제한도 정직하게)
- 데스크톱 3열 / 모바일 아코디언 3단(기본 첫 항목 펼침)

### 4-6. 탭1 — 신청절차 (신규 발명 컴포넌트 ②)
- 4스텝 원형 스텝퍼: 상담신청 → 과정 설계 → 정부 신청·선납 → 교육 진행·환급
- **색 심도 점증**: 스텝 보더·넘버 컬러를 퍼플 20%→45%→70%→100% 단계 적용(에이블런 관찰의 토큰화 — 진행감을 색으로 인코딩)
- 각 스텝 하단 2행 병기: `기업` 행(할 일) / `KG에듀원` 행(함께하는 일) — 행 라벨은 12px 칩. 행정 동행 소구의 시각 증명
- 진입 시 스텝 순차 stagger 60ms(좌→우 시선 흐름 강화). 모바일 세로 타임라인 전환(좌측 연결선 + 세로 스택)

### 4-7. 탭1 — FAQ
- 기존 KEESS FAQ 아코디언 컴포넌트 그대로. 5~7문항(사업 검수 후 문안 교체). 아코디언 morph 240ms, aria-expanded, 다중 열림 허용
- 마지막 항목 아래 "더 궁금한 점은 도입문의로" 인라인 CTA 링크

### 4-8. 탭2 — 필터 칩 + 카드 그리드
- 필터: [전체] + 6카테고리 칩 1행(모바일 가로 스크롤 + 끝단 페이드 힌트). 선택 칩 = 퍼플 채움, 비선택 = ghost. 카운트 병기("승진자 3")
- 필터 적용: 그리드 재배열은 fade-out 120ms → fade-in stagger 40ms(FLIP 이동 애니메이션은 19개 규모에 과잉 — 기각). 필터 상태 URL 쿼리 유지(공유 가능)
- 그리드: 데스크톱 3열 / 태블릿 2열 / 모바일 1열, gap 16px. 정렬 순서 = 성장단계 내러티브 고정, 정렬 옵션 미제공(19개 소량, 탐색 UI 과잉 금지)
- 카드 전체 클릭 영역(≥44px), 카드 = 버튼 시맨틱(aria-expanded로 패널 연동)

### 4-9. 탭2 — 상세 패널 (인라인 확장)
- **데스크톱: 클릭한 카드의 행 아래 전폭 인라인 확장 패널**(그리드 문맥 유지 — 비교 탐색 중단 없음. 모달은 문맥 절단이라 기각, 이동형 상세 페이지는 19개 라우트 과잉이라 기각)
- 패널 열림: height auto morph + 내부 콘텐츠 stagger, 열린 카드에 퍼플 top-stripe 2px(현재 위치 표지). 다른 카드 클릭 시 기존 패널 morph 교체(닫힘→열림 연속 동작)
- **모바일: 바텀시트**(핸들바 + 스와이프 다운 닫기, 배경 dim 40%) — 1열 그리드에서 인라인 확장은 스크롤 점프 혼란
- 패널 내부(위→아래): 공식 신청명 caption(확정 시) → 훈련목표 리스트 → 교육구성 표(영역·학습내용·시간, tabular-nums) → 특장점 3단계(가로 3칩 다이어그램, 개요서 번안) → 운영 메타 행(대상·정원·연중상시·대면/실시간 비대면) → CTA "이 과정으로 도입문의"(과정명 프리셀렉트 상태로 폼 이동)
- 커리큘럼 표가 길면(14H형 5행) 기본 표시, 아코디언 중첩은 금지(아코디언 안 아코디언 = 계층 붕괴)

### 4-10. CTA 밴드 (양 탭 하단 공통)
- 기존 도입문의 폼 컴포넌트 + G2-11 확정 동의 구조 그대로. 탭2에서 진입 시 "관심 과정" 프리셀렉트
- 교육상담 CTA 최상 체감 원칙(기존 확정 원칙) 적용: 밴드 배경만 surface 1단 구분, 폼 필드 수 최소(사업 회신 후 확정)

## 5. 상태 연출
- 정적 SSG 페이지 → skeleton·spinner 해당 없음. IntersectionObserver 진입 reveal만
- 필터 결과 0건 없음(카테고리당 최소 1과정 보장) → empty state 불요, 단 방어 문구 1종은 구현(향후 과정 증감 대비)
- 폼 상태: 기존 확정 문법 상속 — 라이브 인라인 검증(값 유효 시 즉시 .invalid 해제), 제출 성공 토스트
- 탭·아코디언·바텀시트 전부 열림/닫힘 morph, pop 0건
