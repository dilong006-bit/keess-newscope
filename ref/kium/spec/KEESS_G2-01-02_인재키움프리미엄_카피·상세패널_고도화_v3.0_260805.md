## 1. 카피 고도화 (시니어 마케터 확정안)

원칙: ①독자(교육담당자) 주어 ②리드는 결론만(상세는 바로 아래 표·카드) ③검증 사실 범위 내 소구.
공통 문제 진단: 기존 3건은 "주어 없는 설명문"(사전 정의문·챗봇 말투)이라 어색.

(v3.0 초안의 기관 주어 카피는 사용자 리뷰에서 반려 — "너무 길고 User 관점 아님". 아래는 재확정안: 사용자의 질문에 한 문장·15자 안팎으로 답하는 구조.)

| 위치 | 사용자의 속마음 | 현행 | 재확정안 |
|---|---|---|---|
| 지원개요 리드 | "그래서 얼마나 받는데?" | 정부가 훈련비를 지원하는 제도입니다. | **훈련비의 90~95%, 정부가 지원합니다.** |
| 자격확인 리드 | "우리 회사도 되나?" | 무엇을 갖고 계신가요? | **우리 회사도 해당되는지 먼저 확인해 보세요.** |
| 신청절차 리드 | "절차 복잡하면 어떡하지?" | 상담부터 환급까지, 4단계로 함께합니다. | **복잡한 절차, KG에듀원이 끝까지 함께합니다.** |
| 지원개요표 링크 | — | 내 회사 한도 확인하기 | **우리 회사 한도 확인하기** (인칭 통일) |

- 지원개요: 숫자 선행 — 히어로 카피(90~95%)와 톤·수치 일치, 주관기관은 바로 아래 표가 담당
- 자격확인: "먼저" = 문의 전 셀프 확인 가능하다는 편의 소구
- 신청절차: 불안 인정("복잡한 절차") + "끝까지"(4스텝이 실제 환급까지) — "대행" 금지 원칙 유지

## 2. 과정 상세 패널 고도화 전략 (시니어 서비스 기획자)

**진단**: 개요서는 이미 완성된 설득 구조 보유 — 메타 밴드 → 과정목표 → 특장점 3스텝 → 교육구성 표 → 하단 슬로건 배너. 현재 웹 패널은 "스펙"(목표·구성·메타)만 옮기고 "설득"(슬로건·3스텝 설계 논리)을 누락.

**방향**: 신규 창작이 아닌 개요서 설득 구조의 웹 번안 (오제공 0 양립).

**핵심 결정**: 슬로건은 개요서에선 하단 배너지만 웹 패널에선 최상단 승격 — 인쇄물은 순차 열람, 웹 패널은 열자마자 3초 내 가치 전달 필요.

**패널 구조 (재배열)**:
1. 헤더: 카테고리 칩 + titleMarketing + titleOfficial 서브 캡션
2. 슬로건 밴드(신설): slogan 필드 → 퍼플 그라디언트 풀폭 밴드 (개요서 네이비 배너 번안)
3. 메타 pill 4종: 대상·형태·시간·정원 — **단가 계속 미노출**
4. 과정목표: 인용 블록 (좌측 퍼플 보더 + 틴트)
5. 특장점 3스텝: 01 채움 → 02·03 아웃라인 + 화살표 (개요서 도식 그대로)
6. 교육구성 표: zebra + 시간 우측 tabular-nums + 합계 행 (모듈합=hours 검증 완료)
7. CTA: "[관심 과정: X]" 프리필 도입문의 (기존 유지)

**안전장치**: 특장점 헤드라인은 data.ts 필드 존재 시에만 표기(없으면 보고 → 개요서 대조 전사 패치 별도 제공) / 단가 문자열 grep 0건 검증을 보고 항목에 포함.

## 2-1. 관심 영역 '정부 지원' 서브 칩 (추가 요구, 8/5)

**요구**: 도입문의 폼 관심 영역에서 '정부 지원' 칩 선택 시 우측 여백에 서브 칩 4종이 모션과 함께 노출. /kium 경유 인입 시 '인재키움' 기본 선택.

**서브 칩 4종 (지정 라벨 — 사이트 정부지원사업 IA와 일치, 임의 변경 금지)**:
1) 인재키움 2) 아카이브 3) AI기초 4) 내일배움카드

**설계 원칙**:
- 노출 조건: '정부 지원' 부모 칩 선택 시에만 렌더, 해제 시 숨김 + 서브 선택값 초기화
- 모션: 기존 토큰(300ms·var(--ease)) 슬라이드+페이드 인, 칩별 스태거(기존 90ms 체계), reduced-motion 시 즉시 표시
- 선택: 다중 선택 가능, 44px 타깃, 체크박스 시맨틱 (기존 관심 영역 칩 관례 승계)
- /kium 인입: 기존 presetInterests 브리지 확장 — '정부 지원' + 서브 '인재키움' 기본 선택(둘 다 해제 가능)
- **페이로드: 신규 name 필드 추가 금지** — 기존 관심 영역 값에 "정부 지원(인재키움)" 형식 병합(다중 시 "정부 지원(인재키움·아카이브)"), 폼 name 필드 수 15개 유지
- 정보보호 전제 유지: 관심 분류 세분화일 뿐 개인정보 신규 수집 아님 — G2-11 "기존 폼 재사용·신규 수집 0" 전제 불변
