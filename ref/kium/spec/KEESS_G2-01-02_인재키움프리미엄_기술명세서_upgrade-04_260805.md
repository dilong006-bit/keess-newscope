## 2. 카피 시스템 4원칙 (이후 문구 작성·수정 공통 기준)
1. 섹션 리드는 독자(교육담당자) 주어의 한 문장 — "우리가 무엇을 한다"가 아니라 "당신이 무엇을 얻는다/한다"
2. 과장 부사("확실히"·"완벽히"·"최고의")와 느낌표 금지 — 신뢰는 verified 수치와 원천 링크가 만든다
3. "~합니다" 선언형은 혜택("정부가 지원합니다")·동행("함께합니다") 문장에만
4. 인접 섹션 리드의 어미 반복 금지 (현 배치: 지원합니다 → 확인해 보세요 → 함께합니다 → 모았습니다 → 찾아보세요)
