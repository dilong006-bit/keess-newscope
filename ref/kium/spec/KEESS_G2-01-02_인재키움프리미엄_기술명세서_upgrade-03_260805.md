## 2. F20 — GNB 이벤트 칩 강조 (수정 15)

### 2-1. 아이콘 (자체 인라인 SVG, 3D풍 스파클 16×16)
- Flaticon 등 외부 래스터 사용 금지(무료=출처표기 의무·소형 스케일 품질 저하). 아래 사양의 인라인 SVG를 컴포넌트로 제작:
  - 4-point 스파클(다이아 별) path + 우상단 미니 스파클 1개
  - fill: linearGradient #7C3AED → #C4B5FD (기존 mesh 토큰 재사용, 신규 색 0)
  - 유사 입체감: 본체 좌상단에 화이트 40% 하이라이트 스트로크 1점, 하단에 #2E1A6B 20% 셰이드
  - `aria-hidden="true"`, 16px 고정, 기존 dot(span.dot) 대체
- "NEW" 마이크로 라벨: 텍스트 "인재키움 프리미엄" 앞, 9px/800, letter-spacing 0.06em, color #C4B5FD — 지정 문안(임의 변경 금지)

### 2-2. 칩 스타일 (배경·텍스트 불변 — 대비 유지)
- 배경 #2E1A6B·텍스트 13px/700 화이트·radius 999px·44px 터치 타깃: **불변**
- 추가: 보더 1px rgba(124,58,237,.6) + box-shadow 0 0 0 그대로 두고 glow `0 2px 12px rgba(124,58,237,.35)` — 다크/라이트 배경 양쪽에서 분리
- 레이아웃 시프트 0: 글로우·NEW 라벨로 인한 칩 외형 크기 변화가 주변 요소를 밀지 않도록(보더는 box-shadow inset 대체 가능)

### 2-3. 모션 (주기·절제)
- shimmer sweep: `linear-gradient(105deg, transparent 40%, rgba(255,255,255,.25) 50%, transparent 60%)` 오버레이가 좌→우 통과 — **7s 주기, 1s 진행**, ease 기존 var(--ease)
- 스파클 트윙클: scale 1→1.15→1, opacity 미세 변화 — shimmer와 동일 주기 동기화
- hover: glow 강화(.35→.5) + translateY(-2px), 300ms
- `prefers-reduced-motion: reduce`: shimmer·트윙클 애니메이션 완전 제거(정적 글로우·아이콘만)

### 2-4. 접근성·대비
- 텍스트 대비: white on #2E1A6B (기존과 동일 — 변경 없음, AA 이상)
- NEW 라벨(#C4B5FD on #2E1A6B) 대비 확인 — 9px 장식적 보조지만 4.5:1 이상 확인, 미달 시 #D4C5FF 계열로 밝기만 상향 불가(신규 색 금지)하므로 화이트 80%로 대체
- 모션은 의미 전달의 유일 수단 아님(정적 상태로도 위계 성립)
