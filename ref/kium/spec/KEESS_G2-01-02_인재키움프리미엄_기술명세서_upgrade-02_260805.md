## 2. 컴포넌트 계약 상세

### F17 — KiumThumb 타이포 스케일 / KiumCourseCard 본문 타이틀 히든
- KiumThumb 과정명(titleMarketing):
  - font-size **22px** (뷰포트 ≤640px에서 20px), font-weight **700**, line-height 1.3, letter-spacing -0.01em
  - 최대 2줄: `display:-webkit-box; -webkit-line-clamp:2; -webkit-box-orient:vertical; overflow:hidden`
  - 좌하단 앵커·스크림(rgba(20,10,50,.35~.45))·그레인 오버레이·최암부(#1B0F45) 기존 유지
  - 시맨틱: 카드의 제목 요소(h3)가 썸네일 내 텍스트임을 유지 — 본문 타이틀 제거 후에도 헤딩 구조 무손실
- KiumThumb 카테고리 라벨: 11px → **12px** (기타 속성 유지)
- KiumCourseCard 본문: titleMarketing 텍스트 행 **제거**. 잔여 구성 = 카테고리 라벨(+8px dot) · summary · 운영 메타(대상/시간/정부지원 환급 배지)
  - 주석으로 전환 설계 명시: `/* 썸네일 이미지 자산 도입 시(이미지 모드): 배경 텍스트 제거 + 본문 타이틀 복원 */` — 분기 구현은 금지(텍스트 모드 단일)
- 근거(실측): 현행 17px/600 = 카드폭(331px)의 5.1% / 휴넷 정부지원 카드 24px/700 = 5.9% → 텍스트가 유일 비주얼인 우리 카드는 6.6%(22px)로 설정

### F18 — KiumCoursePanel 교육구성 표
- 합계 행("총 {hours}시간"):
  - 배경: 기존 퍼플 틴트 토큰(신규 색 금지), font-weight 700, font-size 본문 대비 +1px(15px 기준 16px)
  - 상단 보더 2px(기존 보더 컬러 계열로 강화), 시간 값은 tabular-nums 우측 정렬 유지
- 셀 패딩: 좌우 16px(첫 열 left / 끝 열 right는 20px), 모바일 12px — 상하 패딩은 현행 유지
- zebra·정렬 등 기존 수정 10 사양 유지

### F19 — titleOfficial 캡션 제거
- 패널 헤더의 "공식 신청명 · {titleOfficial}" 요소 제거 (JSX에서 렌더만 삭제)
- data.ts titleOfficial 필드·값 삭제 금지 (검증 대조·향후 복원 대비)
- 사업 확인 대기 항목: 공식 신청명 고객 고지 필요 여부 → 필요 시 FAQ/각주로 복원 (본 빌드 범위 아님)
