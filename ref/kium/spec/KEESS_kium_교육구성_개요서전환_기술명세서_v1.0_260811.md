## 3. 데이터 모델

### 3-1. 타입 (기존 구조 유지 권장)

```ts
type CurriculumRow = {
  area: string      // 영역        예) '조직 이해'
  content: string   // 주요 학습내용  예) '조직 가치 및 비전 내재화, 경영 시뮬레이션'
  hours: number     // 시간(정수)   예) 2
}
```

- 기존 필드명이 다르면 **기존 필드명을 유지**하고 값만 교체합니다. 타입 변경은 이번 범위 밖입니다.
- `hours`는 **정수로 저장**합니다. `H` 접미사는 표시 계층에서 붙입니다(현행 UI는 숫자만 표시 + 합계행에 `총 N시간`).

### 3-2. 표시 규칙 (현행 유지 — 변경하지 않음)

| 요소 | 규칙 |
|---|---|
| 열 구성 | 영역 / 주요 학습내용 / 시간 (3열) |
| 시간 정렬 | 우측 정렬 + `tabular-nums` |
| 합계 행 | `합계` / `총 {sum}시간` — 퍼플 틴트 배경, weight 700 |
| 합계 값 | **하드코딩 금지.** `rows.reduce((a,r)=>a+r.hours,0)` 로 산출 |
