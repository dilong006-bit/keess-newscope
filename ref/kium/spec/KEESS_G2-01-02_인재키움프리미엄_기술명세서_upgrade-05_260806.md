## 2. 확정안 — 톤온톤 라이트 필 (A안 채택)

| 안 | 내용 | 판정 |
| --- | --- | --- |
| **A. 라이트 틴트 필 + 브랜드 텍스트** | 하위 칩 선택 시 `--p1`의 10% 틴트 배경 + `--p1` 텍스트 + 45% 틴트 보더 | **채택** — 같은 톤 유지("톤은 맞는데 조금 더 연한 색") + 명도 차로 레벨 즉시 인지. 다크 텍스트라 대비 AA 여유 충분 |
| B. 중간 명도 필 + 흰 텍스트 (`--p1` 70% 믹스) | 부모보다 한 단계 연한 퍼플 필 | 기각 — 흰 텍스트 대비가 AA 경계(≈4.5:1)에 걸려 리스크, 부모와의 차이도 A안보다 모호 |

### 2-1. CSS 명세 (그대로 추가)

`styles/components.css`의 `.mchip-sub` 블록(140~144행) 인근에 추가:

```css
/* 하위(세부 분야) 칩 선택 상태 — 부모(.mchip.on)와 동일 톤의 라이트 틴트로 위계 구분.
   신규 토큰 0: --p1 파생 color-mix만 사용 (선례: .nav-chip:hover의 color-mix 패턴) */
.mchip-sub.on{
  background:color-mix(in srgb,var(--p1) 10%,#fff);
  color:var(--p1);
  border-color:color-mix(in srgb,var(--p1) 45%,#fff);
  font-weight:600;
}
```

- **선택자 특이성**: `.mchip-sub.on`(클래스 2개)이 `.mchip.on`(클래스 2개)과 동점이므로 **선언 순서상 `.mchip.on`(133행)보다 뒤에 위치**해야 오버라이드가 성립한다. `.mchip-sub` 블록 뒤(144행 이후)에 두면 자연 충족.
- `font-weight:600`: 라이트 필에서는 색 반전이 없어 선택 강조가 약해지므로 굵기로 선택 상태를 보강 (부모 칩은 흰 텍스트 반전이 그 역할).
- 크기·라운드·패딩·진입 애니메이션·`prefers-reduced-motion` 처리는 현행 유지 — **색·굵기 외 변경 없음**.

### 2-2. 대비 검증 (WCAG AA)

| 조합 | 값 | 대비 |
| --- | --- | --- |
| 텍스트 `#2E1A6B` on 배경(≈`#EAE8F4`, p1 10% 틴트) | 13px/600 | **≈ 11.9:1** — AA(4.5:1) 충족 |
| 보더(≈`#9C92BE`, p1 45% 틴트) vs 배경 | 비텍스트 | 구분선 인지 목적 — 선택/비선택 상태는 배경·텍스트 색으로 이미 구분되므로 보더는 보조 |
