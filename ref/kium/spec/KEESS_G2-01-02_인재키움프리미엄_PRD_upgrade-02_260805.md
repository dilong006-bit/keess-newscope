## 0. 문서 규칙

- 빌드 프롬프트 수정 번호는 3차 개정(수정 9~11)에 이어 수정 12~14

## 1. 고도화 배경 — 3차 개정 화면의 잔여 한계 3가지
1. **썸네일 타이포가 '캡션' 스케일** — 텍스트-온-배경 방식으로 선오픈하는데 과정명이 17px로 작아 썸네일이 아니라 라벨처럼 읽힘. 게다가 카드 본문에 같은 과정명이 한 번 더 노출되어 중복
2. **교육구성 표의 정보 위계 부재** — 총 시간(과정의 핵심 스펙)이 일반 행과 같은 무게, 셀 좌우 여백이 좁아 밀집감
3. **titleOfficial 서브캡션의 효용 부족** — "공식 신청명 · X"는 탐색 단계의 고객에게 의사결정 정보가 아님(마케팅명과 거의 동일한 문자열의 반복 노출)

## 2. 요구사항 해석

**[R10] 썸네일 과정명 폰트 상향 + 본문 과정명 히든 (선오픈 모드)**
- 표면 요청: 배경 위 흰 글자 과정명을 더 크게, 하단(카드 본문) 과정명은 히든
- 진짜 의도: 실사 썸네일 자산이 없는 선오픈 기간에 "텍스트 자체가 썸네일" 역할을 완성 — 카드가 비어 보이지 않고, 같은 정보의 중복 제거
- 해결 문제: 현재 과정명이 카드 대비 5.1% 스케일(캡션급)이라 그리드 전체가 왜소하고, 본문 중복 타이틀이 시선을 분산
- 성공한 모습: 스캔 거리에서 과정명이 첫 시선을 받는 그리드, 이후 썸네일 자산 수급 시 본문 타이틀 복원으로 자연 전환

**[R11] 교육구성 표 — 총 시간 강조 + 좌우 여백 확대**
- 표면 요청: 총 시간이 눈에 띄게, 표 좌우 여백을 더
- 진짜 의도: 교육담당자의 품의 기준 정보(총 몇 시간짜리인가)를 표의 결론으로 승격, 표를 '읽히는 밀도'로
- 성공한 모습: 표를 훑으면 마지막에 "총 N시간"이 자연스럽게 남는 위계

**[R12] titleOfficial(공식 신청명) 미노출**
- 표면 요청: "공식 신청명 · X" 캡션 제거 제안
- 진짜 의도: User에게 도움 안 되는 정보의 노이즈 제거 — 단, 고용24 신청 실무에서 공식명이 필요할 가능성은 별도 관리
- 성공한 모습: 패널 헤더가 마케팅명+슬로건으로 단순해지고, 공식명은 데이터로만 보존

## 4. 변경·신설 기능 명세

### F17 썸네일 타이포 스케일 상향 + 본문 타이틀 히든 (Must)
- 썸네일 과정명: 17px/600 → **22px/700**(모바일 20px), line-height 1.3, letter-spacing -0.01em, 최대 2줄 말줄임, 좌하단 앵커·스크림·그레인 유지
- 썸네일 카테고리 라벨: 11px → 12px (위계 동반 상향)
- 카드 본문의 과정명(titleMarketing) 행 **미노출** — 본문은 카테고리 라벨+dot, summary, 운영 메타만
- 접근성: 썸네일 과정명이 실 DOM 텍스트이므로 스크린리더 제목 역할 유지(h3 시맨틱 확인)
- 대비: 텍스트 확대는 대비값에 영향 없음 — check-contrast 재실행으로 AA(4.5:1) 유지 확인
- **전환 설계(백로그, 코드 주석만)**: 추후 썸네일 이미지 자산 수급 시 '이미지 모드' = 배경 텍스트 제거 + 본문 타이틀 복원. 본 빌드는 텍스트 모드 단일 구현
- Done when: 데스크톱 그리드에서 과정명 22px/700 렌더, 본문 중복 타이틀 0건, 19카드 전건 2줄 이내 표시

### F18 교육구성 표 가독성 (Must)
- 합계 행 강조: "총 {hours}시간" — 배경 퍼플 틴트(기존 토큰), weight 700, 폰트 1단계 상향(본문 15px 기준 16px), 상단 구분 보더 강화
- 셀 좌우 패딩 확대: 현행 대비 최소 +6px(권장 좌우 16px, 첫/끝 열 20px, 모바일 12px)
- Done when: 합계 행이 시각적으로 표의 결론으로 읽히고, 셀 텍스트가 보더에 붙지 않음

### F19 titleOfficial 미노출 (Must)
- 패널 헤더의 "공식 신청명 · {titleOfficial}" 캡션 제거. **data.ts 필드는 삭제 금지**(공식 데이터 보존 — 고용24 신청 실무·검증 대조용)
- 사업 확인 항목 추가: "공식 신청명 고객 고지 필요 여부"(필요 판명 시 FAQ 또는 패널 하단 각주로 복원)
- Done when: 화면 렌더에서 "공식 신청명" 문자열 0건, data.ts titleOfficial 필드 무손실
