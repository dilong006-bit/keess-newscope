## 2. 요구사항 해석

**[R13] 아이콘 등을 활용한 GNB 이벤트 칩 강조 (Flaticon 3D 등 참고)**
- 표면 요청: Flaticon 3D 아이콘 등을 활용해 우측 상단 '인재키움 프리미엄'을 더 눈에 띄게, 진입 유도
- 진짜 의도: 전 페이지 상시 노출되는 유일한 캠페인 진입점의 클릭 유도율을 높이는 것 — 수단이 반드시 Flaticon일 필요는 없음
- 해결 문제: 이벤트 칩이 일반 버튼과 구분되지 않아 상시 노출의 이점이 소실
- 성공한 모습: 어떤 페이지·어떤 배경에서든 GNB에서 첫 시선이 닿는 요소가 이벤트 칩이고, "새로운 것/혜택"의 신호가 1초 안에 전달됨

**[R14] 자격확인 가이드 카드 3장 균형 (03 카드 점선 푸터 비대칭 해소)**
- 표면 요청: 03 카드에만 있는 점선+상담 유도 문구를 ①3장 모두 통일 제공 또는 ②03 점선 제거 + 하단 캡션을 포괄 문구로 변경
- 진짜 의도: 카드 3장의 시각 균형과 정보 배치 논리의 일관성 — 상담 유도는 특정 경로가 아니라 세 경로 공통의 안전망
- 채택안: **②** — 03 카드는 수정 2의 고용24 스텝 추가로 이미 가장 긴 카드라 푸터 반복 시 비대칭 심화. 상담 유도를 섹션 하단 캡션으로 이동해 기존 제외 고지와 통합
- 성공한 모습: 카드 3장이 동일 구조(아이콘·스텝·링크 버튼)로 끝나고, 섹션 캡션 한 줄이 "제외 기준 + 상담 안전망"을 함께 안내

## 4. 기능 명세

### F20 GNB 이벤트 칩 강조 고도화 (Must) — F12 사양 개정(F12′)
원 스펙 F12의 "모션 없음"을 "절제된 주기 모션 허용"으로 개정. 차별화 4축:
1. **아이콘**: 칩 좌측 dot → 자체 SVG 3D풍 스파클(16px)로 교체 — 그라디언트 fill(#7C3AED→#C4B5FD, 기존 mesh 토큰), 화이트 하이라이트 1점
2. **빛(정적)**: 칩에 1px 보더(#7C3AED 60%) + 소프트 글로우(box-shadow, #7C3AED 30~35%) — 다크 히어로·라이트 헤더 양쪽에서 배경과 분리. 배경은 #2E1A6B 유지(텍스트 대비 불변)
3. **움직임(주기)**: ①shimmer sweep — 밝은 하이라이트가 칩을 좌→우로 스치는 효과, 7초 주기 1회·1초 진행 ②스파클 아이콘 미세 트윙클(scale 1→1.15, 동일 주기 동기화). hover 시 글로우 강화+2px lift. prefers-reduced-motion: 모든 주기 모션 제거, 정적 글로우만
4. **NEW 신호**: 칩 우상단 모서리에 초소형 'N' 뱃지 대신 **텍스트 앞 "NEW" 마이크로 라벨(9px/800, #C4B5FD)** — 신규 스코프 오픈(8/19)이라는 사실 기반 표기(임의 문안 아님, 지정 문안)
- 제약 준수: 신규 색 0(전부 기존 토큰), 문안 변경 없음("인재키움 프리미엄" 유지 + "NEW"만 추가), 44px 터치 타깃 유지, 레이아웃 시프트 0(글로우·뱃지는 오버플로 렌더)
- Done when: 다크 히어로·라이트 스크롤 헤더 캡처 양쪽에서 칩이 '교육 상담'보다 시각 우선순위 상위로 읽히고, 텍스트 대비 AA 유지, reduced-motion에서 주기 모션 0

### F21 자격확인 가이드 카드 균형 (Must) — F4′ 부분 개정
- 03 카드의 점선 구분선 + "도입문의를 남겨 주시면 KG에듀원이 지원대상 여부 확인을 도와드립니다" 푸터 **제거** — 카드 3장이 동일 구조(아이콘·스텝·바로가기 버튼)로 종결
- 섹션 하단 캡션을 포괄 문구로 교체(기존 확정 문안 2문장의 결합, 신규 창작 최소):
  - 현행: "대규모기업으로 구분되는 사업장은 환급 대상이 아닙니다."
  - 확정: **"대규모기업으로 구분되는 사업장은 환급 대상이 아닙니다. 확인이 어려우시면 도입문의를 남겨 주세요 — KG에듀원이 지원대상 여부 확인을 도와드립니다."**
- Done when: 03 카드 점선·푸터 렌더 0건, 카드 3장 하단 종결 구조 동일, 섹션 캡션이 확정 문안과 원문 일치
